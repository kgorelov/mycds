** DONE Proper minimum width and hight for widgets and layouts

The idea is to make visibility and position of certain wingets conditional.
Some widgets are mandatory and always visible on the screen: main cd display, level meter, buttons.
Minimum window width and hight: mandatory widgets must stay visible

Optional widgets: CD cover, playlist.
Optinal widgets are visible only when there's enough room for them.
CD cover: aspect ratio within the range of [0.5 .. 1.5], CD covers are quare
Playlist: it shoud have some sensible minimal width so that text doesn't get scrambled. And minimal height.


Then we can support several layouts that can be configured in settings:
  - minimal: cd screen + level meters + buttons, no playlist, no cd cover
  - vertical: playlist under the CD screens, meters and buttons. (no cd cover)
  - horizontal: playlist to the right of cd screen and buttons
  - maximal: like horizontal + cd cover under the cd screen, meters and buttons
  - dynamic (default): defaults to horizontal but depending on the window size may turn into minimal or vertical.

Honestly, I'm not sure if minimal and maximal are true layouts. I guess it's just a question of widgets visibility.
So, yes, the layouts are horizontal and vertical (and dynamic which decides whether it should be horizontal or vertical at the moment).
